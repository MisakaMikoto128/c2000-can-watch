# docs/协议.md（Watch 仓库）

CAN 调试内存读写协议。帧 ID 与 Bootloader 同一套五段式：
`err[28:26] | dev=0x0C[25:22] | cmd[21:16] | dest[15:8] | src[7:0]`，
数据域小端、DLC=8。调试命令仅收单播（dest = 本机地址）。

地址与长度一律按 C28x 字（16 位）计；帧载荷字节序：字 k 低字节在前。

## 命令

### 0x30 读开始 / 0x31 读数据

| 位置 | 内容 |
|---|---|
| 0x30 B0-3 | 起始字地址（小端 32 位） |
| 0x30 B4 | 字数（1~255） |
| 0x30 B5 | 帧间隔 ms（0 = 线速连发） |
| 0x30 B6 | 序号（0x31 B0 原样回显） |
| 0x30 B7 | 0 = 原子快照（受理时关中断整块拷入缓冲），非 0 = 直读 |

0x31 应答：B0 = 序号，B1-7 = 全局字节偏移 [7i, 7i+7) 的数据，末帧不足补 0。
同一时刻只允许一个读事务；新读开始自动作废在途写，新写开始自动作废在途读（单槽互斥）。

### 0x32 写开始 / 0x33 写数据 / 0x34 写应答

| 位置 | 内容 |
|---|---|
| 0x32 B0-3 | 目标字地址 |
| 0x32 B4 | 字数（1~4） |
| 0x32 B5 | 等待写数据的超时 ms |
| 0x32 B6 | 序号 |
| 0x33 | DLC = 字数×2，低字节在前 |
| 0x34 B0 | 序号回显 |
| 0x34 B1 | 状态码：0 成功 / 1 Flash 区拒绝 / 2 字数非法 / 3 等待数据超时 |
| 0x34 B2-5 | 地址回显 |
| 0x34 B6-7 | 长度回显（字数×2） |

写入关中断进行；Flash 地址区间一律拒绝（运行期写 Flash 需要擦除且会破坏固件镜像）。

### 0x35 CRC 校验（单帧请求/应答，无事务状态）

| 位置 | 内容 |
|---|---|
| 请求 B0-3 | 起始字地址（限 Flash 区内） |
| 请求 B4-5 | 字数（≤ CAN_DBG_CRC_MAX_WORDS） |
| 应答 B0-3 | CRC32（与 zlib.crc32 同口径：每字拆两字节、低字节在前） |
| 应答 B4 | 状态码：0 完成 / 1 范围非法 |

上位机用途：把板上固件区 CRC32 与 .out 镜像比对，确认符号文件与板上固件一致后再允许观察与写入。
